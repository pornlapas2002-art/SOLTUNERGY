# Soltunergy — сайт солнечных систем

Одностраничный сайт EPC-компании Soltunergy (Таиланд): пакеты 5–30 кВт, подбор системы «Find Your Perfect Solar», заявки. Языки: RU / EN / TH / 中文 (переключатель в шапке или `?lang=en|th|zh`).

## Файлы
- `index.html` — страница и стили
- `app.js` — логика: каталог, сравнение, опрос, формы, переводы
- `i18n.js` — словарь переводов
- `config.js` — адрес приёма заявок (пусто = демо-режим, заявки никуда не уходят)
- `backend/` — приём заявок через Supabase + Telegram, инструкция в `backend/README.md`

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите содержимое этой папки в его корень.
2. **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

Сборка не нужна — это обычные статические файлы.

> В `config.js` можно хранить только публичный ключ Supabase **anon**. Ключ `service_role` и токен Telegram-бота в репозиторий не добавляйте — они хранятся в секретах Supabase.
